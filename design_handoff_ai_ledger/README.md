# Handoff: AI 가계부 (AI Ledger)

## Overview
"AI 가계부"는 독립 금융앱이 아니라 **기존 AI 개인 비서 앱 안에 편입되는 생활 관리 기능**입니다.
핵심 아이디어: 결제/입금 알림을 기반으로 거래를 **자동 기록**하고, AI가 소비 패턴을 **요약·분석**해 브리핑합니다.
실제 금융 연동은 없고, 프로토타입은 mock 결제 알림 데이터를 사용합니다("시뮬레이션" 버튼으로 거래가 자동 생성됨).

화면은 2개:
1. **소비 달력 홈** (`CalendarHomeScreen`) — 월간 달력 중심 대시보드
2. **소비 리포트** (`ReportScreen`) — 월간 분석

---

## About the Design Files
이 번들의 파일들은 **HTML로 만든 디자인 레퍼런스**입니다 — 의도한 룩앤필과 동작을 보여주는 프로토타입이며, 그대로 복사해 쓰는 프로덕션 코드가 아닙니다.
작업 목표는 **이 디자인을 대상 앱(AI 비서 앱)의 기존 프론트엔드 환경에 맞게 다시 구현**하는 것입니다 — 그 앱이 쓰는 기존 패턴/라이브러리(React, Vue, SwiftUI, Flutter 등)를 따르세요.

참고로 이 번들에는 **바로 참고 가능한 Flutter 구현 2종**이 함께 들어 있습니다:
- `flutter_main_standalone.dart` — 단독 실행형 (`flutter run` 즉시 실행, 하단 내비 포함)
- `flutter_ai_ledger_screen.dart` — 기존 앱 편입형 단일 파일 (`CalendarHomeScreen()`으로 바로 사용)

대상 앱이 Flutter가 아니라면 위 Dart 코드는 **레이아웃·색·간격·상태 로직의 정답지**로 참고하고, 실제 구현은 대상 프레임워크로 옮기세요.

HTML 프로토타입(`ai_ledger_prototype.html`)은 `support.js`가 같은 폴더에 있어야 열립니다(브라우저에서 파일 열기).

## Design System (요약)
- **폰트**: Pretendard (미보유 시 시스템 산세리프 폴백). 숫자·금액 가독성 강조, 음수 letter-spacing으로 조밀하게.
- **배경**: 화이트(#FFFFFF) 중심. 카드는 흰 배경 + 얇은 테두리 또는 연회색 fill(#F5F7FA).
- **포인트 컬러**: 블루 #3B6EF6 (토스와 구분되는 인디고 톤).
- **강조 카드**: AI 브리핑만 딥네이비 그라디언트 → "단순 가계부가 아닌 AI 비서"라는 정체성 표현.
- **모양**: 둥근 카드(반경 14~22px), 넉넉한 섹션 간 여백(12~16px).
- **아이콘**: 라인 아이콘(Flutter 기본 Material outlined 아이콘으로 대체 가능).

## Screens / Views

### 1) CalendarHomeScreen — 소비 달력 홈
**Purpose**: 앱 진입 시 첫 화면. 월간 소비를 달력으로 한눈에 보고, 날짜를 눌러 그날의 AI 브리핑과 거래 내역을 확인. 결제 알림 자동 감지가 이 앱의 차별점이므로 함께 노출.

**Layout** (세로 스크롤 ListView, 좌우 패딩 20):
1. **헤더**: "12월 내 소비"(23/700) + 아래 화살표, 우측 알림 벨(40×40 원형 #F2F4F6, 우상단 빨강 점 배지).
2. **상단 탭**: `달력 / 거래 내역 / 소비 분석` — 하단 밑줄 인디케이터(선택 시 #3B6EF6, 2.5px). 기본 선택 "달력". **"소비 분석" 탭 → ReportScreen으로 Navigator.push.**
3. **월 요약**: 좌측 "지출 1,625,560원"(ink) / "수입 2,746,059원"(blue) 2줄, 우측 chevron.
4. **월간 달력 (핵심, 가장 큰 영역)**: 요일 헤더(일=빨강, 토=파랑) + 7열 GridView. 각 셀 = 날짜 숫자 원(27×27, 선택일은 #EAF0FF 원+파란 숫자, 일요일 숫자 빨강) + 그날 지출(-금액, 회색 8px) + 수입(+금액, 파랑 8px). 셀 종횡비 약 0.72, 행 간격 4.
5. **선택 날짜 AI 브리핑 카드** (딥네이비 그라디언트): 상단 sparkle 아이콘칩 + "AI 소비 브리핑" + 우측 "12월 N일", 본문은 친절한 비서 말투.
6. **선택 날짜 거래 내역**: "12월 N일 · X요일" 제목 + 우측 합계. 흰 카드 안 거래 행 리스트(아바타 이니셜 38×38 + 상호명 + 시간·카테고리 태그·분류방식 + 우측 금액). 거래 없으면 "이 날은 기록된 소비가 없어요" 빈 상태.
7. **자동 감지 (축소형)**: 연블루 카드(#F7F9FF/테두리 #E3EAFB). 헤더 = 파란 점 + "결제 알림 자동 감지" + "N건" 배지 + 우측 "시뮬레이션". 대기 거래 행마다 아바타·상호명·카테고리 태그·상태 배지(확인필요=orange / 자동분류·AI n%=green) + 우측 금액 + [확정][수정][삭제] 미니 버튼.
8. **예산 초과 (한 줄 알림)**: 연오렌지 배너 — 경고 아이콘칩 + "이번 달 카페 예산의 84%를 사용했어요" + chevron.

### 2) ReportScreen — 소비 리포트 (월간 분석)
**Purpose**: 한 달 소비를 자세히 분석. AppBar "소비 리포트" + 뒤로가기.

**Layout** (세로 스크롤 ListView, 좌우 패딩 20):
1. **헤더**: "2025년 12월"(24/700) + 아래 화살표.
2. **기간 세그먼트**: `주간 / 월간 / 연간` pill 세그먼트(배경 #F2F4F6, 선택 흰 알약+그림자). 기본 "월간".
3. **잔액 요약 카드** (#F5F7FA): "이번 달 잔액" + 261,500원(32/700) + 하단 지출/수입 미니 스탯 2개(흰 서브카드).
4. **카테고리별 소비**: 흰 카드. 제목 + "총 220,000원". 상단 누적 막대(카테고리색, 비율 flex, 높이 12, 반경 7). 아래 행 리스트: 색점 + 이름 + % + 금액.
5. **예산 사용률**: 흰 카드. 항목마다 이름 + %(초과 시 orange) + "사용/한도" + LinearProgressIndicator(초과 orange, 그 외 blue).
6. **반복 결제·고정지출**: 흰 카드. 제목 + "월 86,000원". 항목: 아바타 + 이름 + "주기 · 카테고리" + 금액.
7. **월간 AI 브리핑**: 딥네이비 그라디언트 카드(제목 "12월 AI 소비 브리핑" + 본문).

## Interactions & Behavior
- **날짜 선택**: 달력 셀 탭 → `selectedDay` 변경 → AI 브리핑 카드와 거래 내역이 그 날짜 기준으로 갱신. 상세 데이터가 있는 날: 5·17·20·26일. 기본 선택 20일.
- **탭 이동**: "소비 분석" 탭 → `ReportScreen` push. "달력"/"거래 내역"은 내부 `topTab` 상태 전환(현재 프로토타입은 달력 뷰 위주).
- **결제 알림 시뮬레이션**: "시뮬레이션" 탭 → `simPool`에서 순환으로 mock 거래 1건을 대기 목록 맨 위에 추가(0.3s 페이드/슬라이드 인).
- **확정**: 해당 대기 거래 제거(기록 확정 의미).
- **수정**: 상태를 "확인 필요" → "직접 수정"(신뢰도 100%)으로 변경, 배지 green 전환.
- **삭제**: 대기 거래 제거.
- 실제 API 없음 — 전부 로컬 mock 상태.

## State Management
- `selectedDay: int` (기본 20)
- `topTab: int` (0 달력 / 1 거래내역 / 2 소비분석 — 2는 push라 상태로 남지 않음)
- `pending: List<PendingTx>` (자동 감지 대기 목록), `_simIdx`, `_nextId`
- 리포트 화면은 정적 mock (상태 없음)

## Mock Data
`flutter_ai_ledger_screen.dart`의 `MockData` 클래스에 전부 정의됨:
- `dayData`: 일별 지출/수입 합계(달력 표시용)
- `txByDay`: 날짜별 상세 거래 리스트
- `briefingByDay`: 날짜별 AI 브리핑 문구
- `initialPending` / `simPool`: 자동 감지 초기·시뮬레이션 풀
- `recurring`: 반복 결제 목록
- 리포트의 categories/budgets는 `ReportScreen.build` 내 인라인 리스트

## Assets
- 이미지 에셋 없음. 모든 아이콘은 라인 아이콘(HTML은 인라인 SVG, Flutter는 Material `*_outlined`).
