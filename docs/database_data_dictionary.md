# 데이터 사전

## 온디바이스 원본
- `planner_items`: 일정/To-do 공통
- `event_details`: 일정 시간/장소
- `todo_details`: 할 일 상세
- `reminders`: 준비물/출발/날씨 알림
- `user_memories`: 선호/장소/반복 패턴
- `emotion_logs`: 동의 기반 감정 기록
- `briefings`: 브리핑 결과
- `ai_local_requests`: 마스킹된 처리 감사 기록

## 서버 최소 데이터
마스킹된 요청·응답, 룰/모델 버전, 평가 결과, 오류 로그만 저장합니다.
