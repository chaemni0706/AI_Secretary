# 인증사진 기능 범위

## 공통 원칙

- VLM은 사진에서 관찰 가능한 객체, 장면, 텍스트, 시각 증거만 추출한다.
- `verified`, `rejected`, `retake_required` 최종 판정은 Rule Engine만 결정한다.
- 테스트는 Mock 및 Fixture 기반으로 수행하며 실제 OpenAI API를 호출하지 않는다.

## 운동 인증

현재 `exercise` 프로토타입은 선택한 운동과 관련된 장소, 기구, 환경이 사진에서 확인되는지만 판정한다.
실제 운동 수행 완료를 증명하지 않는다.

현재 범위에서 제외하는 데이터:

- 운동 시작/종료 시각
- 체류시간 및 운동 지속시간
- 러닝 거리, GPS 경로, 걸음 수
- 수영 랩
- 웨어러블 운동 기록
- Health Connect 연동
- 실제 칼로리
- 실제 운동 완료 판정

향후 실제 운동 수행 인증을 확장할 때는 앱 세션, 촬영 시각, 위치, 체류시간, 센서/웨어러블 연동, 운동별 완료 기준을 별도 설계해야 한다.

## 기상 인증

기상 인증 PoC는 사진 내용보다 서버 기준 시각을 핵심 판정 기준으로 사용한다.

- 세션 발급 시 서버가 `server_issued_at`, `expires_at`, `display_time`을 반환한다.
- `display_time`은 향후 앱 카메라 화면에 보여줄 안내용 서버 시각이다.
- 제출 판정은 서버가 기록한 `received_at`과 예정 기상시간 허용 범위로 결정한다.
- `scheduled_at`은 timezone offset을 포함한 ISO datetime이어야 한다. 예: `2026-07-02T07:00:00+09:00`.
- 휴대전화 시스템 시간, EXIF 시간, 사진 속 시계/텍스트는 신뢰 가능한 최종 판정 기준으로 사용하지 않는다.
- 이미지 품질 문제는 기본 2회까지 `retake_required`로 세션을 유지하고, 초과 시 세션을 `rejected`로 종료한다.
- 갤러리 업로드 차단은 향후 프론트엔드 앱에서 구현한다.
- 현재 백엔드 PoC는 앱 내 카메라 촬영 후 업로드되는 상황을 가정한다.
- 세션은 DB 없이 인메모리에 저장되므로 서버 재시작 시 사라진다.
